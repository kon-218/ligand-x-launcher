Performance

How many CPU-based jobs (docking, batch) run at the same time. Raise this on machines with many CPU cores; lower it if the machine feels sluggish.

Simultaneous MD, ADMET, and Boltz-2 jobs. Each job uses significant GPU memory — keep at 1 or 2 unless you have a high-VRAM GPU.

ABFE / RBFE jobs are long-running. Keep at 1 unless you have multiple GPUs.

Quantum Chemistry

Choose the extracted Linux x86-64 ORCA folder containing a file named orca. This is required even on Windows or macOS because Quantum Chemistry runs in a Linux container. Ligand-X tests the install inside the pinned QC worker before every start.

Troubleshooting

Restores the CPU and memory limits to the shipped defaults and re-fits them to this computer. Use this if services fail to start after editing the configuration by hand. Your password, version and other settings are not affected.

Resource limits reset.

Advanced

Direct access to the configuration file docker compose reads. Only needed for options this screen does not offer.

Danger zone

Stops and deletes every Ligand-X container, network, downloaded image and stored result, then removes the runtime files and the launcher itself — leaving this computer as it was before you installed. Shared images such as PostgreSQL and Redis are left alone in case other software uses them. This cannot be undone.

Environment file

ORCA installation

Quantum Chemistry needs your separately licensed Linux x86-64 ORCA install. Choose the extracted folder containing a file named orca (not orca.exe). Ligand-X mounts it read-only and runs a short isolated check in the pinned QC worker before services start.
